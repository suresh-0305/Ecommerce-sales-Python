# E-commerce Sales Data Analysis (EDA)

## Project Overview
This project focuses on analyzing e-commerce sales data using Python to understand customer behavior, product performance, and overall sales trends.

## Objectives
- Analyze sales performance across different product categories.
- Understand customer demographics based on age, gender, and location.
- Identify top-performing products and sales trends.
- Generate meaningful business insights through data visualization.

## Dataset Description
The dataset contains information such as:
- Order ID
- Customer ID and Customer Name
- Age and Gender
- City and State
- Product Category and Product Name
- Quantity
- Unit Price
- Total Price

## Tools and Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Data Analysis Process
1. Data loading and inspection.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Customer and product performance analysis.
5. Data visualization and insight generation.

## Visualizations
- KPI analysis
- Bar charts
- Donut charts
- Shape maps
- Matrix tables

## Key Outcomes
- Identified sales trends across product categories.
- Analyzed customer distribution by demographics and location.
- Evaluated product performance and sales patterns.
- Presented findings through visualizations to support business understanding.
